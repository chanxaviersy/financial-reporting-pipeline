# 开发笔记

## 踩过的坑

### 1. 时区问题

- **问题**：跨时区数据对比时差异巨大
- **解决**：统一存 UTC，显示时转本地
- **代码**：`src/ingestion.py` 用 `pd.to_datetime(utc=True)`

### 2. 浮点累加误差

- **问题**：财务金额累加 1 千万次后差 0.01
- **解决**：用 `Decimal` 类型，关键计算不用 float
- **代码**：`src/reconciliation.py`

### 3. Excel 模板格式丢失

- **问题**：用 openpyxl 修改模板后样式丢失
- **解决**：用 `openpyxl` 的 `load_workbook` + `copy` 模式
- **代码**：`src/reporting.py`

### 4. 告警风暴

- **问题**：同一异常触发 N 次告警
- **解决**：告警去重（`dedup_window=1h`）
- **代码**：`src/alerts.py`

## 性能优化

- **批量插入**：`executemany` 代替逐行 insert
- **增量更新**：用 `updated_at > last_run` 过滤
- **并行对账**：3 源对比用 `concurrent.futures`
- **缓存**：质量检查结果缓存 1 小时

## 财务领域经验

### 对账

- **3 源对账**：订单系统 / 财务系统 / 银行流水
- **差异容忍度**：< 0.01 元（避免浮点误差）
- **差异处理**：人工审核 + 系统留痕

### 风险监控

- **指标设计**：从历史异常中提炼规则
- **阈值**：宁可漏报，不要"狼来了"
- **告警分级**：P0 立即 / P1 1小时内 / P2 24小时内

## 审计要求

- 所有操作留日志
- 关键数据不可物理删除（用 `is_deleted` 标志）
- 报告 PDF 含数字签名
